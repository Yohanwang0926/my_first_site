01從 Hello World 開始，也很好。C++ / 起點+

第一支程式的價值，是讓「寫程式 → 編譯 → 執行」真的走完一次。下一步可以改輸出文字、加入輸入，再刻意製造一個小錯誤，練習讀懂編譯器訊息。

std::cout << "Hello, 67!";
02遇到 bug，先縮小問題。DEBUG / 方法+

先記下預期結果與實際結果，找出能重現問題的最小輸入。一次只改一件事，再觀察結果；讓假設有證據，比一直亂改更有用。

03個人網站，就是一個小型實驗。WEB / 實作+

HTML 決定內容結構、CSS 決定外觀、JavaScript 加上互動。先把內容做清楚，再用手機和鍵盤實際操作，確認每個人都能順利閱讀。
